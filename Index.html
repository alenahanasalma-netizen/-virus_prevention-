Cheat sheet

The lineup

All four at a glance. The big difference is whether you have to do something for it to spread.

MalwareNeeds you to act?How it gets inWhat it wrecksBest shield
Virus
Usually
You open a file or plug something in.
Exploits a weak spot, attaches a code file to the system, then propagates.
Slow computer, corrupted files, data deleted on its own.
Antivirus, updates, checking USB drives.
Worm
No
It copies itself on its own.
Networks and storage media, no user interaction needed.
Performance drops, growing slowness, network paralysis.
Security patches.
Trojan horse
Yes
You download or install it.
Disguised as a legit app or program.
Espionage, slow internet, laggy computer, data corruption or loss.
Official downloads only, no pirated software.
Ransomware
Often
A fake email or a sketchy site starts it.
Security holes, leaked or weak passwords, malicious websites.
Financial loss, data leaks, reputation damage, operations down.
Updates, fake-email radar, tested recovery.
